# Tracy Gemayel - Professional Portfolio Website

A modern, responsive, and engaging portfolio website for Tracy Gemayel, a professional psychomotor therapist specializing in neurological rehabilitation and developmental disorders.

## 📋 Project Overview

This portfolio website showcases:
- **Professional Services** - Comprehensive therapy services and specializations
- **Experience** - Work history across multiple healthcare centers and institutions
- **Education & Training** - Academic credentials and clinical internships
- **Skills & Languages** - Trilingual (English, Arabic, French) professional
- **Volunteer Work** - Community service and humanitarian contributions
- **Contact & Booking** - Easy way for patients and referral partners to connect

### Responsive Design
- **Mobile-First Approach**: Optimized for all device sizes

### Accessibility

## 📋 Customization Guide

### Change Color Scheme
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #0066cc;
    --accent-color: #00cc99;
    /* ... other colors */
}
```

### Update Content
Edit `index.html` to:
- Update personal information
- Modify service descriptions
- Add new experience entries
- Update education details
- Add testimonials (if desired)

### Add Images
Replace the image placeholders:
```html
<div class="image-placeholder">
    <img src="your-image.jpg" alt="Description">
</div>
```
